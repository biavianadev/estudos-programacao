# Estudos - Programação

[![Status](https://img.shields.io/badge/Status-Em%20Andamento-yellow)](#)

**Olá!** 

Este repositório é dedicado à organização de anotações, exercícios e projetos desenvolvidos ao longo dos meus estudos em programação.

O objetivo é construir uma base sólida em programação, principalmente com Python, e explorar suas aplicações em Matemática, Ciência de Dados e Inteligência Artificial.

---

## Estrutura das Pastas

Os conteúdos serão organizados por área de estudo. Cada pasta poderá conter:

```text
conteudo/
├── resumo.md
├── exercicios.py
└── assets/
```

- **resumo.md:** conceitos, explicações e exemplos.
- **exercicios.py:** exercícios e implementações práticas.
- **assets/:** imagens, gráficos e materiais complementares.

> A estrutura poderá variar conforme a necessidade de cada conteúdo.
