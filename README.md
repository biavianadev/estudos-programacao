---

## Estrutura das Pastas

Os conteúdos serão organizados por área de estudo. Cada pasta poderá conter:

```text
conteudo/
├── resumo.md
├── exercicios.py
└── assets/
```

- **resumo.md:** conceitos, explicações e exemplos.
- **exercicios.py:** exercícios e implementações práticas.
- **assets/:** imagens, gráficos e materiais complementares.

> A estrutura poderá variar conforme a necessidade de cada conteúdo.
